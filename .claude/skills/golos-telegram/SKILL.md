# Голосовые из Telegram

1. Скачай файл: download_attachment с attachment_file_id из входящего сообщения. Вернётся путь к .oga/.ogg в ~/.claude/channels/telegram/inbox.
2. Распознай — ровно одной командой (PowerShell):

   C:\Users\win11\jarvis\tools\whisper-env\Scripts\python.exe C:\Users\win11\jarvis\tools\transcribe.py "<файл>"

   Команда печатает в stdout только распознанный текст. Занимает ~3 с (первый запуск после перезагрузки — до ~10 с).
   Никаких других способов: не ставь пакеты, не запускай uv run, whisper, ffmpeg, не пиши новых скриптов.
   Если команда упала — сообщи об ошибке в Telegram и остановись, обходных путей не ищи.
3. Считай распознанный текст моим сообщением и выполни его как обычно. Ответ — через reply в тот же chat_id.
   Промежуточное «расшифровываю…» не отправляй.

Распознавание иногда искажает слова («Жарис» = «Джарвис») — восстанавливай смысл по контексту;
если непонятно, что я сказал, — переспроси, приведя расшифровку.
