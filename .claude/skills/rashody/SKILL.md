# Учёт расходов

Таблица: Google Таблица «Расходы», лист Sheet1 (или первый лист).
ID таблицы: НЕ_ЗАДАН
Если ID не задан — найди таблицу через search_spreadsheets / list_spreadsheets по названию «Расходы»;
если её нет — создай с заголовками в строке 1: Дата | Категория | Сумма | Комментарий.
Найдя ID, впиши его в этот файл вместо НЕ_ЗАДАН, чтобы не искать каждый раз.

## Запись траты
1. Разбери сообщение: сумма, категория, комментарий, дата. В одном сообщении может быть несколько трат — запиши каждую отдельной строкой.
2. Дата: по умолчанию сегодня (Europe/Moscow); «вчера», «в субботу» и т.п. — пересчитай. Формат ГГГГ-ММ-ДД.
3. Сумма — число без валюты и пробелов (500, а не «500 ₽»). Валюта по умолчанию рубли; если другая — укажи в комментарии.
4. Категория — строго одна из списка:
   Продукты, Кафе и рестораны, Транспорт, Такси, Дом и ЖКХ, Связь и подписки,
   Здоровье, Одежда, Развлечения, Подарки, Образование, Техника, Другое.
   Подбирай сам, не переспрашивай. Сомневаешься — «Другое».
5. Найди первую пустую строку: прочитай столбец A (get_sheet_data, range A:A), следующая после последней заполненной.
   Запиши через update_cells. НИКОГДА не перезаписывай существующие строки.
6. Ответь одной строкой: «✅ Записал: 500 ₽ · Продукты · сегодня». Если трат несколько — списком, без лишних слов.

## Исправление и удаление
«Удали последнюю», «там было 700, а не 500», «это было такси» — найди нужную строку
(по умолчанию последнюю), покажи её и попроси подтверждение, потом измени.
Удаление = очистка ячеек строки пустыми значениями.

## Отчёты
«Сколько я потратил за неделю/месяц/на еду?» — прочитай таблицу, посчитай сам и выведи:

**Расходы за октябрь 2026: 12 450 ₽**
- 🛒 Продукты — 5 200 ₽ (42%)
- 🚕 Такси — 2 100 ₽ (17%)
- …
Топ-3 самые крупные траты одной строкой каждая.
Если просят сравнение — сравни с прошлым таким же периодом (+/− в ₽ и %).
Суммы форматируй с пробелом между тысячами.
