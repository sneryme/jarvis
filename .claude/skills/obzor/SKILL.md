\# Единая сводка дел



Определи период из вопроса (по умолчанию — сегодня + 7 дней). Часовой пояс: Europe/Moscow.

Собери данные из ВСЕХ источников, даже если спросили только про «задачи» или только про «мероприятия»:



1\. Google Calendar — пройди по ВСЕМ календарям из list\_calendars.

&#x20;  В list\_events всегда передавай

&#x20;  eventType: \["DEFAULT","BIRTHDAY","OUT\_OF\_OFFICE","FOCUS\_TIME","FROM\_GMAIL"].

2\. Google Tasks (google-tasks) — все списки задач: задачи со сроком в периоде

&#x20;  и невыполненные просроченные.



Выведи ОДНИМ ответом, по дням, в хронологическом порядке:



\*\*Пн, 5 октября\*\*

\- 🎂 День рождения: …

\- 📅 Мероприятие: … (время)

\- ✅ Задача: …



В конце отдельным блоком: ⚠️ Просроченные задачи (кратко, не больше 5, остальные — числом).

Пустые дни не показывай. Если за период ничего нет — скажи одной строкой.

Время всех событий показывай по Москве; события на весь день — без времени.
